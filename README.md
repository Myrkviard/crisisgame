# Crises d'Entreprise — Jeu de cartes

Jeu de 30 cartes sur les grandes crises d'entreprise réelles, avecBudget épreuve de communication de crise.
2 à 8 joueurs • 30 cartes • ~20 minutes.

## Contenu du dépôt

```
pdf/
  Crises_dEntreprise_30_cartes_A4.pdf         ← version imprimeur, 300 dpi (22 Mo, 10 pages)
  Crises_dEntreprise_30_cartes_A4_light.pdf   ← version allégée 200 dpi (7 Mo, 10 pages)
cartes/
  card_01_perrier.png … card_30_azf.png       ← les 30 cartes en fichiers individuels (300 dpi)
  dos.png                                     ← dos unique du jeu
```

## Impression

1. **Papier** : A4 250-300 g/m² (paprès photo brilliant pour un rendu premium).
2. **Impression** : recto-verso, **sans** mise à l'échelle (« Taille réelle / 100 % »), qualité maximale.
   - Recto : pages 1 à 5
   - Verso : pages 6 à 10
   - Pour un alignement recto/verso parfait, activez le retournement **sur le bord long**.
3. **Découpe** : chaque carte fait **63 × 88 mm** (format carte à jouer) avec **3 mm de fond perdu**.
   Coupez en suivant les traits de coupe gris imprimés dans les marges ; en cas de léger écart, le fond perdu évite les liserés blancs.
4. Optionnel : passez une couche de vernis-adhésif plastifié pour un touch « carte premium ».

## Règle express

1. Le joueur pioche une carte et lit la crise à voix haute.
2. Il dispose d'**1 minute** pour improviser une conférence de presse face aux autres joueurs.
3. Les autres joueur·euse·s votent : si sa communication est jugée **convaincante**, la perte de Réputation est **réduite de moitié** (ex. −20 → −10).
4. Premiere à atteindre le seuil convenu de Réputation perdue (ex. −60) est éliminé(e).

### Échelle de gravité

| Couleur | Gravité | Impact |
|---|---|---|
| Jaune | Grave | −10 Réputation |
| Orange | Très grave | −15 Réputation |
| Rouge | Critique | −20 Réputation |
| Noir | Catastrophique | −30 Réputation |
